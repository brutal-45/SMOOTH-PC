## 🛠️ Quick Start

1. **Create a Restore Point** (Windows)
   - Press `Win + R`, type `sysdm.cpl`, press Enter
   - Go to "System Protection" tab
   - Click "Create" and follow the prompts

2. **Choose Your Optimization**
   - Select from the table above based on your needs

3. **Follow the Guides Carefully**
   - Read each guide thoroughly before making changes
