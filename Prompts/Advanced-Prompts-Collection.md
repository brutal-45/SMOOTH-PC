## ✍️ Text Generation Prompts

### Content Writing

#### Blog Post Outline
```
Create a comprehensive blog post outline about [TOPIC]. 
Include: catchy title options, engaging introduction hook, 
5-7 main sections with subheadings, key points for each section, 
call-to-action conclusion, and SEO keyword suggestions. 
Target audience: [AUDIENCE]. Tone: [TONE].
```

#### Email Template
```
Write a professional email template for [PURPOSE]. 
Structure: compelling subject line, personalized greeting, 
clear opening statement, detailed body paragraphs, 
specific call-to-action, professional sign-off. 
Keep it concise (150-200 words). Tone: [FORMAL/CASUAL/FRIENDLY].
```

### Creative Writing

#### Story Starter
```
Generate 5 unique story prompts in the [GENRE] genre. 
Each should include: an intriguing protagonist with a flaw, 
a compelling conflict or challenge, an unexpected twist element, 
and a vivid setting. Make them original and thought-provoking.
```

#### Character Development
```
Create a detailed character profile for a [ROLE] in a [SETTING] story. 
Include: name, age, physical description, personality traits (3 strengths, 3 weaknesses), 
backstory (3 key events), motivations, fears, relationships, 
unique quirks, and character arc potential.
```

### Technical Writing

#### Documentation
```
Write technical documentation for [PRODUCT/FEATURE]. 
Sections needed: overview, prerequisites, step-by-step installation, 
configuration options, usage examples, troubleshooting common issues, 
FAQ section. Use clear, concise language suitable for [SKILL LEVEL] users.
```

#### API Explanation
```
Explain the [API/FUNCTION] in simple terms. Include: 
what it does, when to use it, parameters with descriptions, 
return values, code example in [LANGUAGE], common pitfalls, 
and best practices. Add a real-world use case scenario.
```

## 🔧 Prompt Engineering Tips

### Best Practices

1. **Be Specific**: Detailed descriptions yield better results
2. **Use References**: Mention artists, styles, or eras
3. **Layer Information**: Start broad, add details progressively
4. **Experiment**: Try variations of successful prompts
5. **Save Winners**: Keep a library of effective prompts

### Parameter Guide (Midjourney)

| Parameter | Function | Example |
|-----------|----------|---------|
| `--ar` | Aspect Ratio | `--ar 16:9` |
| `--v` | Version | `--v 5.2` |
| `--q` | Quality | `--q 2` |
| `--style` | Style Mode | `--style raw` |
| `--niji` | Anime Model | `--niji 5` |
| `--s` | Stylize | `--s 750` |
| `--chaos` | Variation | `--chaos 50` |

### Negative Prompts (What to Avoid)

Add these to exclude unwanted elements:
```
--no blurry, distorted, deformed, ugly, duplicate, watermark, text, signature
```
